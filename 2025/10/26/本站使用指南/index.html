欢迎来到沽名的博客

这里记录我学习计算机与算法时整理的笔记，也会分享一些个人思考。文章主要面向正在入门和复习相关知识的读者；内容来自我的学习过程，遇到错误或过时信息时欢迎指出。

从哪里开始读

算法与数据结构

  • 二分查找与三分查找：从有序数组边界、二分答案和单峰函数开始。
  • 高精度：学习用数组表示大整数及基本运算。
  • 链表：了解节点、指针、删除、反转和快慢指针。
  • KMP 算法：通过前缀函数理解字符串匹配。
  • STL 功能与使用：按使用场景选择常见 C++ 容器。

可以先读概念和小例子，再尝试文章末尾的练习。阅读代码时建议自己输入一组小数据，跟踪变量变化，而不是只复制模板。

数据库

**MySQL 学习心得（一）**从表、InnoDB 索引和 B+ 树入门，后续会继续补充 SQL 和数据库原理笔记。

其他内容

博客也有个人规划与工具使用方面的记录。这些内容属于阶段性经验，适用时间和个人背景有限，请结合自己的情况判断。

文章与代码

文章中的练习题解和部分项目代码会放在我的 GitHub 仓库：GuMing1234/GuMing1234。如果链接失效，可以从仓库首页按目录查找。代码可能会随平台和依赖更新而变化，使用前请阅读对应项目说明。

反馈与勘误

如果发现代码错误、概念不准确或链接失效，可以在文章评论区留言，也可以通过我的 GitHub联系我。我会尽量补充修正，并在文章中更新内容。

博客仍在持续整理中。与其把笔记写得很长，我更希望每篇文章都能说明问题、前提、实现和容易出错的地方。
