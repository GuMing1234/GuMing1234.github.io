高精度整数：从表示到基本运算

当题目中的整数超过 C++ 内置整数类型的范围时，可以把数字拆成一位一位的十进制数，再用数组模拟竖式运算。这类方法通常称为高精度。

1. 什么时候需要高精度

常见的 int 通常只能表示约 21 亿范围内的整数；long long 通常能表示到约 9.22 × 10^18。具体范围由类型标准和实现决定，写题时可使用 <limits> 查看上限。

例如 100! 约有 158 位，无法放进 long long。高精度能按题目需要保存更多位，但运算会比内置整数慢，也要自己处理进位、借位和前导零。

2. 统一数字表示

本文用 vector<int> 保存非负整数，低位放在下标 0。例如十进制数 5072 表示为 {2, 7, 0, 5}。计算完成后去掉多余的高位零，但至少保留一位，因此 0 表示为 {0}。

本文的函数处理非负整数；减法要求被减数不小于减数。负数需要额外保存符号，本文先不扩展到带符号大整数。

3. 运算过程

加法

从低位到高位逐位相加，把上一位进位加进来。当前位写 sum % 10，进位写 sum / 10。最后可能还剩一位进位，需要追加到结果。

减法

先保证 a >= b，逐位相减；若当前位不够减，就向高位借 1（也就是当前位加 10）。运算后从最高位去掉多余的 0。

乘法

第 i 位与第 j 位的乘积，先累加到结果的第 i + j 位，再统一处理进位。两个有 n、m 位的数，朴素乘法时间复杂度为 O(nm)。

除以小整数

从高位向低位扫描，维护当前余数 rem。把新的一位接到余数后面，商的当前位为 current / divisor，新的余数为 current % divisor。

5. 常见错误

  • 数字倒序存储后，输出时要从最高位倒着输出。
  • 数组或 vector 必须初始化，不能读取未赋值的结果位。
  • 处理进位时要预留额外位数。
  • 去前导零时要保留 0 本身，避免结果变成空容器。
  • 减法要先比较大小；若允许负数，需要另行维护符号。
  • 除法要检查除数非零，并确认中间变量不会溢出。

本文覆盖的是竞赛中常见的非负整数运算。高精度除以高精度、负数、十进制小数可以作为后续专题补充；不要把普通 double 当作任意精度小数使用。
